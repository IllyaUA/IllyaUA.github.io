# IntegratIQ – GitHub Pages site

Static site, no build step. Upload the contents of this folder to a repository and enable Pages.

1. Create a repo (`<user>.github.io` for a root URL, or any repo name).
2. Push these files to `main`.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root.

Before publishing, edit in `index.html`:
- GitHub link in the header (currently `https://github.com/`).
- The "IntegratIQ Website, coming soon" chip once the main site exists.
- Hero art: `assets/hero.jpg` is cropped from the design mockup. Replace it with the original artwork (about 2000×900) for sharper results.

Dark mode follows the system setting and the toggle remembers the choice. No external fonts or scripts are loaded.
